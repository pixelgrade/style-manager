# Installation

As a standard WordPress plugin, installation is the same as most other plugins. The stable public release is served by WordPress.org.

Style Manager requires WordPress 6.5 or later and PHP 8.1 or later.

## Zip File

1. Install Style Manager from the _Plugins -> Add New_ screen by searching for `Style Manager`, or download the stable zip from [WordPress.org](https://wordpress.org/plugins/style-manager/).
2. Go to the _Plugins &rarr; Add New_ screen in your WordPress admin panel and click the __Upload Plugin__ button at the top.
3. Upload the zipped archive.
4. Click the __Activate Plugin__ link after installation completes.
